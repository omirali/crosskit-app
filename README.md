# CrossKit

CrossKit — локальный control plane для координации сессий Claude Code и Codex: один трей-агент на macOS, который видит все ваши агентские сессии, стримы работы и позволяет делиться доступом с друзьями через end-to-end зашифрованный P2P-слой.

## Скачать

Последняя версия — во вкладке [Releases](https://github.com/omirali/crosskit-app/releases/latest). Скачайте `CrossKit_<версия>_aarch64.dmg`, откройте и перетащите CrossKit в Applications.

Приложение подписано и нотарizировано Apple — никаких предупреждений Gatekeeper и `xattr` не требуется.

Только macOS (Apple Silicon).

## Автообновления

CrossKit сам проверяет наличие новых версий и предлагает установить обновление в один клик.
