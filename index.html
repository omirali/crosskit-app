Один трей — все сессии

CrossKit автоматически находит все ваши сессии Claude Code и Codex по проектам и показывает живой статус каждой.

Стримы работы

Группируйте связанные сессии в стримы, следите за прогрессом и историей изменений в едином таймлайне.

P2P-друзья, E2E-шифрование

Делитесь доступом к стримам с коллегами напрямую — вопросы и ответы шифруются end-to-end, ни один сервер не видит содержимое.

Локальный брейн

Полнотекстовый поиск и ИИ-ответы по истории ваших сессий — работает локально, токены тратятся только когда вы сами об этом просите.

Автообновление

CrossKit сам проверяет новые версии и предлагает установить обновление в один клик — без ручной загрузки DMG.

Подписано и нотаризовано

Приложение подписано сертификатом Developer ID и нотаризовано Apple — открывается сразу, без предупреждений и обходных команд.

Локально-первая архитектура

Все ваши данные о сессиях хранятся локально на вашем Mac. Firebase используется только как точка встречи для обмена сообщениями между устройствами и никогда не видит содержимое ваших вопросов и ответов — они шифруются end-to-end статическими ключами устройств ещё до отправки.
